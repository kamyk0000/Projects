# 🎮 Kick Down!
[**PL**]
**Kick Down** to gra typu Sim‑cade Racing / Adventure, skupiająca się na japońskim stylu wyścigów Touge 1v1, 
łącząca elementy Prędkości (_racing_) i Stylu (_drifting_) w ręcznie opracowanej, cel‑shadingowej oprawie wizualnej. 
Gra została stworzona w silniku **Unreal Engine 5.7**, korzystając wyłącznie z systemu **Blueprints**.

Projekt został zbudowany z naciskiem na responsywną, dynamiczną i modularną podstawę dla:
- Różnych modeli samochodów, fizyki i animacji
- Modularnego systemu audio silnika
- Logiki kierowców AI
- Logiki wyścigów (P2P, Circuit)
 -Scen środowiskowych (eksploracja i narracja)
- Systemów UI
- Obsługi inputu i haptyki
- Ustawień i dostępności

---

[**EN**]
**Kick Down** - is a Sim-cade Racing / Adventure game that focuses on the Japanese Style Touge 1v1 events, incorporating a blend of Speed (_racing_) and Style (_drifting_) in crafted cell-shaded visual style.
The game was created using **Unreal 5.7** game engine with the sole use of **Blueprints**.

The project was built with a focus on responsive, dynamic, and modular foundation for:
- Various Car models, physics and animations
- Modular engine audio
- AI drivers logic
- Race logic (P2P, Circuit)
- Environmental scenes (discovery and storytelling)
- UI systems
- Input handling and haptic response
- Settings and accessibility
